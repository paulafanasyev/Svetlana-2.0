# Безопасность веб-версии (ссылка / PWA)

Веб-версия Светланы (например, на Vercel) удобна для просмотра и проб, но у браузера есть
принципиальное ограничение: **любой секрет, который страница может использовать, может прочитать
и скрипт, выполняющийся на той же странице.** Это свойство платформы, а не ошибка кода.

## Что уже защищает

- Строгая CSP (`script-src 'self'`, без inline и eval) вшивается в сборку: чужой скрипт не
  загрузится и не встроится через текст сообщения.
- Заголовки хостинга (`vercel.json`): HSTS, запрет встраивания в чужие сайты, nosniff,
  no-referrer, ограниченный Permissions-Policy, COOP.
- Ключи в браузере хранятся зашифрованными (AES-GCM, неизвлекаемый ключ WebCrypto); в localStorage
  открытые ключи не пишутся никогда. Это защищает от кражи файлов профиля, но не от
  скрипта на самой странице.
- Данные из документов, CRM и веба помечаются как недоверенные; вызовы инструментов
  проходят строгую проверку схемы; опасные действия требуют подтверждения.

## Правила

1. **Основные (платные) ключи держите в приложении для Windows.** Там ключ лежит в Диспетчере
   учётных данных Windows, в JavaScript не попадает, а его изменение и первый запрос к каждому
   облачному ИИ подтверждаются в нативном окне.
2. **В веб-версии — только тестовые или бесплатные ключи** (например, Groq) с лимитом расходов
   в кабинете провайдера, либо локальная модель (Ollama) без ключей вообще.
3. **Для публичного сайта используйте серверный прокси** (`/api/ai-proxy`): ключ хранится на
   сервере, браузер получает только ответы. Прокси должен проверять вход пользователя
   и ограничивать частоту запросов.
4. Не устанавливайте незнакомые расширения браузера в профиль, где открыта Светлана: расширения
   видят страницу целиком.
5. Веб-версия не управляет телефоном: мост к телефону работает только из приложения для Windows
   (браузер запрещает https-странице ходить в локальную сеть).
