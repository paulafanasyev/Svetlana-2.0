# Светлана 2.0 для Windows

В репозитории две разные программы для Windows:

| Что | Зачем | Где взять |
| --- | --- | --- |
| **Светлана 2.0** (это приложение, Tauri) | чат и голос, выбор ИИ, CRM, связь с телефоном | Actions → «Build Windows Desktop Installer» → артефакт `SvetlanaSetup-Windows` (файл `Svetlana-2.0_<версия>_x64-setup.exe`) |
| **Светлана для Windows** (агент «руки на ПК», Python) | даёт Светлане управлять этим компьютером | Releases, теги `desktop-v*` (ветка `svetlana-core-v2`, папка `core/desktop-agent`) |

## Установка Светланы 2.0

1. Скачай `Svetlana-2.0_<версия>_x64-setup.exe` и запусти. Установщик по-русски, ставит программу для текущего пользователя и, если нужно, сам докачивает WebView2.
2. Установщик пока без цифровой подписи: если SmartScreen предупредит, «Подробнее» → «Выполнить в любом случае».
3. При первом запуске откроется мастер настройки:
   - **★ Светлана Сервер**: вставь ключ `ASSISTANT_KEY_SVETLANA2` (на сервере: `grep ASSISTANT_KEY_SVETLANA2 /etc/svetlana/backend.env`) → «Подключить». Windows спросит «Сохранить ключ?» и «Разрешить отправить переписку?», нажми ОК в обоих окнах.
   - **Ollama**: установи Ollama, выполни `ollama pull qwen2.5:7b`, нажми «Найти Ollama» → «Использовать».
4. Пиши в «Чат со Светланой». Мастер можно открыть снова кнопкой «Настройка» справа вверху.

Ключи облачных ИИ лежат в Диспетчере учётных данных Windows и не попадают в интерфейс; запрос в облако делает нативная часть и каждый новый разговор спрашивает разрешение в окне Windows.

## Сборка

`cargo tauri build --bundles nsis` из `src-tauri/`. Tauri сам запускает `npm run build` (beforeBuildCommand) с `TAURI_ENV_PLATFORM`,
поэтому в сборку не попадает веб-CSP (она блокировала бы вызовы нативной части). Версия одна: `src/version.ts` = `package.json` = `tauri.conf.json` = `Cargo.toml`
(проверяет `src/__tests__/desktopRelease.test.ts`).
