# Личное файловое хранилище ИИ-агента

Функция доступна в чате персонального агента, если включён переключатель **«Разрешить инструменты, браузер и хранилище»**.

## Как использовать

Попросите агента создать отдельное хранилище и сохранить заметку, например: «Создай своё локальное хранилище и сохрани план проекта в notes/plan.md». Агент использует инструменты:

- agent_workspace_create — создать личное пространство;
- agent_workspace_status и agent_workspace_list — проверить состояние и список файлов;
- agent_workspace_read — прочитать файл после подтверждения;
- agent_workspace_write — создать или явно перезаписать файл;
- agent_workspace_delete_file и agent_workspace_remove — удалить файл или всё пространство.

## Границы хранения

- Данные хранятся на текущем устройстве в локальном хранилище сайта/приложения и не отправляются в облако самим хранилищем.
- Это не папка Android, доступная через файловый менеджер, и это не произвольный доступ ко всей файловой системе.
- При чтении файла его содержимое передаётся выбранному ИИ-провайдеру; такой вызов требует подтверждения.
- Пространство привязано к ID одного агента. Другой агент не может указать произвольный ID в аргументах инструмента.
- Относительные пути без ..; максимум 100 файлов и 2000 символов на файл. Хранилище ограничено общим лимитом, чтобы не заполнить localStorage.
- Очистка данных сайта/приложения может удалить локальные данные; экспортируйте важные материалы.

## Браузер

Изолированный Browser Worker — отдельный Node.js + Playwright/Chromium процесс, который нужно установить и запустить локально. Текущая CI-проверка подтверждает сборку фронтенда, Android-модуля и Windows-инсталлятора, но не доказывает, что Chromium Worker встроен в APK или установлен на телефоне. Для Android нужен отдельный совместимый локальный runtime; данный PR его не добавляет.
