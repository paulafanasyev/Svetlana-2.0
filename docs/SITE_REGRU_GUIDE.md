# Сначала три слова, которые нужно понять

**Домен** — адрес сайта, например *moy-sait.ru*. Его покупают на год и продлевают.

**Хостинг** — компьютер в интернете, на котором лежат файлы сайта и который показывает их людям. Его тоже оплачивают помесячно или за год.

**DNS** — «телефонная книга» интернета: по адресу *moy-sait.ru* она говорит браузеру, на каком хостинге лежит сайт. Если домен и хостинг куплены в REG.RU вместе, всё настраивается само.

> **Что такое Beget?** Просто другая компания-хостинг, как REG.RU. В этой инструкции он **не нужен**: всё делаем в одном месте, в REG.RU.

**GitHub** — место, где хранится код сайта. Если сайт лежит на GitHub, его можно настроить так, чтобы после каждого изменения он сам выкладывался на хостинг.

# Что понадобится

- Почта и телефон для регистрации.
- Банковская карта (или СБП) для оплаты.
- Файлы сайта: архив `.zip` или репозиторий на GitHub.
- 30–40 минут. Сам сайт начнёт открываться через 1–24 часа после покупки (это время нужно DNS).

# Шаг 1. Регистрация в REG.RU

1. Откройте **reg.ru** и нажмите **«Войти» → «Зарегистрироваться»**.
2. Укажите почту и телефон, подтвердите код из письма или SMS.
3. Заполните данные владельца (ФИО, паспорт). Для домена .ru это требование закона: без этого домен не выдадут.

# Шаг 2. Купить домен и хостинг вместе

1. На главной странице введите желаемое имя в поиск доменов и нажмите **«Подобрать»**.
2. Если имя свободно, нажмите **«В корзину»**.
3. В корзине REG.RU предложит хостинг. Выберите тариф виртуального хостинга с панелью **ispmanager** (самый простой подойдёт для обычного сайта-визитки или лендинга).
4. Нажмите **«Оплатить»** и оплатите картой или по СБП.

> **Почему вместе?** Тогда REG.RU сам «привяжет» домен к хостингу, и DNS настраивать не нужно.

**Если домен уже был куплен раньше**, а хостинг покупаете сейчас: после покупки хостинга домену нужно указать DNS-серверы хостинга **ns1.hosting.reg.ru** и **ns2.hosting.reg.ru**. Это может сделать Светлана (см. шаг 5) или вы сами: **Мои домены → домен → DNS-серверы и управление зоной → Изменить → ns1.hosting.reg.ru, ns2.hosting.reg.ru**.

# Шаг 3. Найти панель хостинга

1. Откройте **Личный кабинет → Мои услуги → Хостинг**.
2. На карточке хостинга нажмите **«Панель управления»** — откроется **ispmanager**.
3. На той же карточке есть раздел **«Доступы»**: там логин (вида *u1234567*), пароль, адрес сервера и данные **FTP**. Они понадобятся в шаге 6.

# Шаг 4. Выложить сайт вручную (самый простой способ)

1. В ispmanager откройте **«Сайты»**, выберите свой домен и нажмите **«Файлы сайта»**.
2. Удалите всё, что там лежит (это страница-заглушка). Папку **webstat**, если есть, оставьте.
3. Нажмите **«Загрузить»** и выберите архив сайта (`.zip`).
4. Выделите архив, нажмите **«Извлечь»**.
5. Проверьте, что файл **index.html** (или index.php) лежит прямо в папке сайта, а не во вложенной папке. Если во вложенной — перенесите всё содержимое на уровень выше.
6. Откройте свой адрес в браузере. Если видите старую заглушку, подождите: DNS обновляется до 24 часов.

**Бесплатный HTTPS (замочек в браузере):** в ispmanager откройте **«SSL-сертификаты» → «Создать» → Let's Encrypt** и выберите свой домен.

# Шаг 5. Что может сделать Светлана

Откройте в Светлане **«Сервисы»** и подключите **REG.RU**:

1. В личном кабинете REG.RU откройте **Настройки → Настройки API**.
2. Задайте **пароль для API** (он отдельный от пароля входа).
3. В **«Диапазоны IP-адресов»** добавьте свой внешний IP (его показывает, например, сайт 2ip.ru). Без этого REG.RU не пустит Светлану.
4. В Светлане вставьте в поле подключения **логин:пароль_API** через двоеточие и нажмите **«Подключить»**.

Теперь можно просить словами, например:

- «Какие у меня домены и когда их продлевать?»
- «Какой у меня баланс в REG.RU?»
- «Поставь домену moy-sait.ru DNS-серверы ns1.hosting.reg.ru и ns2.hosting.reg.ru»
- «Добавь TXT-запись для подтверждения Яндекс.Вебмастера»

Каждое изменение Светлана **показывает и ждёт вашего подтверждения**. Без нажатия «Подтвердить» ничего не меняется.

> **Чего Светлана не делает:** не покупает и не оплачивает домены и хостинг. Деньги списываются только вашими руками в личном кабинете REG.RU.

# Шаг 6. Сайт из GitHub, который обновляется сам

Если код сайта лежит на GitHub, можно сделать так: вы меняете файл на GitHub, и через минуту изменения уже на сайте.

## 6.1. Подключить GitHub к Светлане

1. На GitHub: **Settings → Developer settings → Fine-grained tokens → Generate new token**.
2. Срок 30–90 дней, **Repository access**: только репозиторий сайта.
3. Права (**Permissions**): **Contents — Read and write** и **Workflows — Read and write**.
4. Скопируйте токен (начинается с *github_pat_*), в Светлане откройте **«Сервисы» → GitHub**, вставьте и нажмите **«Подключить»**.

## 6.2. Сохранить пароль FTP в GitHub (делаете вы)

Пароли Светлана в GitHub не записывает: это делаете вы сами, один раз.

1. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
2. Создайте три секрета, значения возьмите из раздела «Доступы» хостинга (шаг 3):
   - **FTP_SERVER** — адрес сервера FTP;
   - **FTP_USERNAME** — логин FTP;
   - **FTP_PASSWORD** — пароль FTP.

## 6.3. Попросить Светлану настроить автовыкладку

Скажите Светлане: *«Добавь в репозиторий &lt;имя&gt; автодеплой на хостинг REG.RU по FTP в папку www/moy-sait.ru»*. Она предложит создать файл `.github/workflows/deploy.yml` и покажет его на подтверждение. Его содержимое:

```yaml
name: Выкладка на хостинг
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: SamKirkland/FTP-Deploy-Action@v4.3.5
        with:
          server: ${{ secrets.FTP_SERVER }}
          username: ${{ secrets.FTP_USERNAME }}
          password: ${{ secrets.FTP_PASSWORD }}
          server-dir: www/moy-sait.ru/
```

Вместо *moy-sait.ru* — ваш домен. Точную папку сайта видно в ispmanager → «Сайты» → «Файлы сайта».

После этого любой коммит в ветку **main** сам выкладывает сайт. Посмотреть, получилось ли, можно во вкладке **Actions** репозитория (зелёная галочка — всё хорошо) или спросить Светлану: *«Как прошла последняя выкладка?»*

# Если что-то не так

| Что видите | Что делать |
|---|---|
| Открывается заглушка REG.RU | Подождите до 24 часов после покупки или смены DNS-серверов |
| «Сайт не найден» | Проверьте DNS-серверы домена: для хостинга REG.RU это ns1.hosting.reg.ru и ns2.hosting.reg.ru |
| Пустая страница или «Index of /» | Файл index.html лежит не в папке сайта, а во вложенной. Перенесите файлы на уровень выше |
| Светлана пишет про IP-адрес | Добавьте свой IP в REG.RU → Настройки API, затем в «Сервисах» нажмите «Обновить» |
| Красный крестик в Actions на GitHub | Проверьте три секрета FTP и папку в server-dir |
| Перестала приходить почта на домен | Почтовые (MX) записи пропали при смене DNS: попросите Светлану показать DNS-записи и добавить MX вашего почтового сервиса |

# Коротко

1. Зарегистрироваться на REG.RU.
2. Купить домен + хостинг вместе, оплатить.
3. Загрузить архив сайта в ispmanager или настроить автовыкладку с GitHub.
4. Включить бесплатный SSL.
5. Подключить REG.RU и GitHub в Светлане, чтобы управлять доменом, DNS и выкладкой словами.
