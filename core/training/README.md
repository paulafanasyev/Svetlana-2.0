# Обучение Светланы

**Одна модель, обученная всему.** Учится на настоящих инструментах ядра (47 шт.): схемы и системные промпты берутся из кода, каждый вызов в датасете проходит ту же проверку `validate()`, что и в бою. Два режима одной модели: **помощница Павла** (все инструменты) и **Пико для детей** (только детские инструменты, без денег, устройств и кода; вход `/api/pico/chat` по `SVETLANA_PICO_TOKEN`).

**Основа — Gemma 4** (`SV_FAMILY=gemma`, по умолчанию): `phone` = E2B, `pc` = E4B. Она понимает картинки и звук и сама умеет вызывать инструменты. Прежняя основа Qwen2.5 (3B/7B, только текст) осталась: `SV_FAMILY=qwen`. Разметка чата и формат вызовов берутся из шаблона самой модели, поэтому один и тот же код учит и экзаменует обе.

**Чему учится (65 сценариев):**
- **Продукты** (`docs_search`, справочник `knowledge/products`): как устроены и работают АИКО, «Мир самозанятых», «Я-Зарядка» и сама Светлана, с файлом-источником.
- **АИКО:** поиск, сравнение, отзывы, заказы, доставка, возвраты, кабинет продавца, аналитика.
- **Мир самозанятых:** клиенты, задачи, напоминания, договоры (create → set_data → generate), гранты, биржа проектов.
- **Законы и НПД** (`knowledge_search`, `knowledge/npd.json`): всегда со статьёй.
- **Учёт, CRM, календарь, документы, картинки, видео.**
- **Компьютер:** любая программа через скриншот и список элементов (UI Automation или распознавание текста): 1С, Render, браузер. Проведение и оплата только после подтверждения.
- **Программирование**, в том числе самой Светланы (новый инструмент, правка, тесты).
- **Пико:**
  - эталоны новых упражнений из видео (`exercise_template_create`, пакет для приложения);
  - оценка попыток;
  - репетитор без готовых ответов (`math_check`), уроки, рисование по шагам;
  - безопасность детей.

| Файл | Что делает |
|---|---|
| `colab_train.py` | всё в Colab одной командой: зависимости → датасет → обучение версий `pc` и `phone` → экзамен по категориям → GGUF (+ файл зрения mmproj, если собрался) → выкладка в Releases. `SV_ADAPTER=путь` — только экзамен готового адаптера |
| `build-dataset.mjs` + `scenarios-extra.mjs` + `scenarios-brain.mjs` | `data/train.jsonl` и `data/eval.jsonl`: повторы ≤5, экзамен не пересекается с обучением, отложенные формулировки вопросов |
| `eval.mjs` | экзамен через OpenAI-совместимый адрес: инструмент и аргументы (кроме свободного текста), ключевые числа в ответах, 0 опасных вызовов |
| `../../model/get.py` | скачать готовую Светлану для компьютера или телефона |

Без `GH_TOKEN` веса остаются в `/content/svetlana-out`, а LoRA копируется на Google Диск, если он подключён в ноутбуке. На T4 нет bf16, поэтому Gemma 4 там считается в float32: медленнее, но работает.

Честно о границах:
- Законы и устройство продуктов модель не заучивает: она ищет в базах знаний, поэтому базы нужно обновлять.
- Gemma 4 умеет смотреть на картинки, но датасет пока текстовый: экран на ПК Светлана получает списком элементов. Обучение на скриншотах — следующий шаг.
- Экзамен проверяет решения на новых комбинациях и формулировках, а не общий интеллект.
