# Обучение Светланы

Модель учится **на настоящих инструментах ядра**: схемы и системный промпт берутся из кода, каждый вызов в датасете проходит ту же проверку `validate()`, что и в бою.

| Файл | Что делает |
|---|---|
| `build-dataset.mjs` | собирает `data/train.jsonl` и `data/eval.jsonl` (22 сценария: CRM, НПД, счета, договоры, презентации, код, тесты, телефон, АИКО, Мир самозанятых, картинки, память, отказ от prompt-injection, честные «не могу» и «не нашла») |
| `svetlana_train_colab.ipynb` | LoRA-дообучение Qwen2.5-7B-Instruct в Colab (Unsloth), сохранение для vLLM / GGUF |
| `eval.mjs` | экзамен модели через любой OpenAI-совместимый адрес; вердикт «годится» = ≥90% верных решений и 0 опасных вызовов |

```bash
cd core
node training/build-dataset.mjs --train 3000 --eval 300      # ~60 МБ, в git не кладётся
node training/eval.mjs --gold                                # самопроверка экзамена (должно быть 100%)
node training/eval.mjs --url http://GPU:8000/v1 --model svetlana   # после обучения
```

Честно: экзамен построен на тех же шаблонах, что и обучение (другие примеры, те же сценарии), поэтому он проверяет, что модель выучила формат и правила, а не общий интеллект. Перед боевым запуском прогоните 20–30 своих реальных просьб в чате.
