# Обучение Светланы

Модель учится **на настоящих инструментах ядра** (41 шт.): схемы и системный промпт берутся из кода, каждый вызов в датасете проходит ту же проверку `validate()`, что и в бою.

**Что умеет после обучения** (47 сценариев): CRM и задачи, учёт НПД (доходы, расходы, отмена, отчёты, таблицы), вопросы о самозанятых, налогах, договорах и законах — через `knowledge_search` со ссылкой на статью (`knowledge/npd.json`), счета, договоры (в т.ч. через «Мир самозанятых»), презентации, картинки и видео, календарь («напомни завтра в 10»), голосовое управление ПК и телефоном (распознанная речь без знаков препинания), код, разбор зарядки и планы тренировок (формулы ya-zaryadka-ai), поиск товаров и заказы АИКО, гранты, честные «не знаю/не могу», отказ от prompt-injection.

| Файл | Что делает |
|---|---|
| `colab_train.py` | всё в Colab одной командой: зависимости → датасет → LoRA → экзамен → сохранение |
| `build-dataset.mjs` + `scenarios-extra.mjs` | генерируют `data/train.jsonl` и `data/eval.jsonl`; повторы ≤5, экзамен не пересекается с обучением, для базы знаний — отложенные формулировки вопросов |
| `eval.mjs` | экзамен модели через OpenAI-совместимый адрес: инструмент и аргументы должны совпасть (кроме свободного текста), в текстовых ответах — те же ключевые числа; 0 опасных вызовов |
| `svetlana_train_colab.ipynb` | та же команда в виде ноутбука |

## Colab
```
!git clone -b svetlana-core-v2 https://github.com/paulafanasyev/Svetlana-2.0 && cd Svetlana-2.0/core && python training/colab_train.py
```
GPU: T4 → Qwen2.5-3B, 1200 примеров (~1,5–2 ч); L4 → 7B, 2000; A100 → 7B, 3000. Переопределить: `SV_MODEL`, `SV_TRAIN`, `SV_EPOCHS`.
Сохранение: LoRA — на Google Диск (если подключён в ноутбуке), полная модель — в `/content/svetlana-out`, `HF_TOKEN`+`HF_REPO` (полная модель на Hugging Face), `SV_GGUF=1` (Ollama/LM Studio).

## После обучения
```bash
vllm serve ./svetlana-merged --served-model-name svetlana --enable-auto-tool-choice --tool-call-parser hermes --max-model-len 16384
node training/eval.mjs --url http://GPU:8000/v1 --model svetlana
```
Затем в «ИИ-провайдеры» Светланы: preset `vllm`, адрес `http://GPU:8000/v1`, модель `svetlana`.

Честно о границах: законы модель не «зубрит» — она учится искать в базе знаний и цитировать источник; базу (`knowledge/npd.json`) нужно обновлять при изменении законов. Экзамен проверяет формат и правила на новых комбинациях и формулировках, а не общий интеллект: перед боем прогоните 20–30 своих реальных просьб.
