# Светлана для компьютера: руки, глаза и голос

## Windows: установка за минуту (всё локально, с версии 2.2.0)

1. Откройте **Releases** репозитория → последняя версия «Светлана для Windows» → скачайте `SvetlanaSetup-X.Y.Z.exe`.
2. Запустите установщик → «Далее» → «Готово». Права администратора не нужны.
   Если Windows покажет «Система Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае» (установщик пока без цифровой подписи).
3. Поставьте **Ollama** (ollama.com) и скачайте модель, которая видит экран и умеет вызывать инструменты:
   `ollama pull qwen3-vl:8b` (≈6 ГБ, нужно 8+ ГБ видеопамяти или 16 ГБ ОЗУ). Другую модель можно вписать в окне Светланы.
4. Откройте Светлану. Режим **«На этом компьютере»** включён по умолчанию: ядро запускается здесь же на `127.0.0.1`,
   ключ устройства выдаётся автоматически, копировать ничего не нужно. Статус станет 🟢.
5. Скажите: **«Светлана, который час?»** или нажмите **«💬 Открыть чат»** (пароль входа скопируется сам).

Облачные ИИ (OpenAI, Claude, DeepSeek, GigaChat, YandexGPT…) подключаются в чате → «ИИ-провайдеры»: ключи хранятся только в ядре на вашем ПК.
Если у вас своё ядро на VPS — выберите режим **«Свой сервер»** и вставьте адрес и ключ из вкладки «Устройства».

Светлана живёт в трее рядом с часами и стартует вместе с Windows (можно выключить в настройках).
Русская модель распознавания речи уже внутри установщика: звук **не уходит в интернет**, в ядро отправляется только распознанный текст.
Для озвучки нужен русский голос Windows: «Параметры → Время и язык → Речь → Добавить голоса → Русский» (обычно уже стоит: Irina).

## Голосовые команды

Скажите «Светлана» и команду, одной фразой или с паузой («Светлана…» → «Слушаю» → команда). После ответа ещё 6 секунд можно продолжать без слова «Светлана».

**Мгновенно и без интернета:**

| Скажите | Что будет |
|---|---|
| который час / какое сегодня число | время, дата, день недели |
| открой калькулятор / Excel / Telegram / 1С / ВС Код | запуск программы из меню «Пуск» |
| открой ютуб / почту / госуслуги / мой налог | сайт в браузере |
| громче / тише / громче на 20 / без звука | громкость |
| пауза / продолжи / следующий трек | музыка и видео |
| таймер на 5 минут / на полчаса | таймер с голосовым напоминанием |
| сделай скриншот | файл в «Изображения\Светлана» |
| заряд батареи | процент и зарядка |
| сверни все окна / закрой окно / заблокируй компьютер | окна и экран |
| загугли … | поиск в Яндексе |
| что ты умеешь | список команд |
| стоп / повтори / новый разговор | служебные |

**Всё остальное думает мозг Светланы** (локальная модель или подключённый облачный ИИ): «открой Блокнот и напиши список дел», «открой 1С и найди счёт Иванова», «напиши письмо клиенту».
Мозг смотрит экран, нажимает и печатает по шагам (до 40 шагов на задачу), каждое действие мышью и клавиатурой подтверждается.

**Подтверждения.** Рискованное Светлана переспросит: ответьте «да» или «нет».
Голосом подтверждаются только обычные изменения и действия на **этом** компьютере. Деньги, публикации, запуск кода и другие устройства — только в приложении: голос можно подделать записью или услышать из колонок.

## Без установщика (Windows / macOS / Linux)

```bash
pip install -r requirements.txt -r requirements-desktop.txt
python svetlana_desktop.py                 # окно + трей; режим «На этом компьютере» найдёт node и ../server.mjs сам
# или без окна, к своему серверу:
python agent.py --url wss://ваш-домен/ws/device --token dev_... --voice
```
Модель речи скачается при первом запуске (≈45 МБ) в папку пользователя.

## Сборка установщика

**Автоматически (рекомендую):** `.github/workflows/svetlana-windows.yml` собирает `SvetlanaSetup-X.Y.Z.exe` при каждой правке `core/desktop-agent/**` и кладёт в Releases (тег `desktop-vX.Y.Z`). Новая версия: поменять `version.py`.
Перед упаковкой сборка проверяет на настоящем Windows: встроенный Node запускает ядро, оно выдаёт ключ устройства и пускает руки и глаза только по нему (`test/local_core_check.py`).

**Вручную на Windows:** установите Python 3.12 и Inno Setup 6, затем в папке `core\desktop-agent`:
```powershell
pip install -r requirements.txt -r requirements-desktop.txt pyinstaller
powershell -ExecutionPolicy Bypass -File packaging\build_windows.ps1
```
Готовый установщик: `packaging\Output\SvetlanaSetup-X.Y.Z.exe`.

## Файлы

- `agent.py` — руки и глаза (скриншоты, клики, ввод) + связь с ядром
- `local_core.py` — ядро на этом же компьютере: запуск, пароль, локальный ИИ, автоматический ключ устройства
- `voice.py` — уши (Vosk, офлайн), голос (SAPI5), слово-активатор, подтверждения «да/нет»
- `commands.py` — быстрые офлайн-команды
- `svetlana_desktop.py` — окно и трей для Windows
- `packaging/` — PyInstaller + Node + ядро + Inno Setup + шаблон GitHub Actions
