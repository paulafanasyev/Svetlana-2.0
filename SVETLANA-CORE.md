# Светлана 2.0: ядро, веб-приложение, «Светлана Руки» (Android) и агент для ПК

Один ИИ-агент на вашем сервере. Пишет и правит код, ведёт CRM и учёт НПД, делает документы, PDF-презентации и счета, работает с маркетплейсом АИКО и «Миром самозанятых», говорит голосом, видит экран и управляет телефоном/ПК, если вы дали доступ. Подключается к любым ИИ-провайдерам: своя модель в РФ (vLLM), YandexGPT, GigaChat, OpenAI, Anthropic, DeepSeek, OpenRouter, Gemini, Mistral, Groq, Ollama, LM Studio.

## Состав
| Папка | Что это |
|---|---|
| `core/` | сервер на Node 22, без зависимостей: агент, инструменты, провайдеры, WebSocket-хаб устройств, PWA |
| `core/web/` | веб-приложение (ставится на телефон как приложение): чат, голос, CRM, финансы, устройства, провайдеры |
| `core/runner.mjs` | песочница для запуска команд кода (отдельный контейнер без сети) |
| `core/desktop-agent/` | агент для Windows/macOS/Linux: экран, мышь, клавиатура, список приложений |
| `core/connectors/self-employed-stp.js` | адаптер для бэкенда «Мира самозанятых» |
| `android-hands/` | Android-приложение «Светлана Руки» (AccessibilityService): видит экран, приложения, нажимает |

Иконки и аватар лежат текстом в `core/web/assets.b64.json` и распаковываются автоматически (`npm start`, `npm test`, Docker).

## Быстрый запуск (Docker, любой VPS: Timeweb/Reg.ru/Selectel)
```bash
cd core && cp .env.example .env
# заполните SVETLANA_ADMIN_TOKEN (≥16 символов) и SVETLANA_SECRET (openssl rand -hex 32)
sudo mkdir -p /srv/svetlana/{data,workspace} && sudo chown -R 1000:1000 /srv/svetlana
DOMAIN=svetlana.example.ru docker compose up -d --build
```
Caddy сам выпустит HTTPS. Откройте `https://ДОМЕН`, войдите паролем из `SVETLANA_ADMIN_TOKEN`, во вкладке «ИИ-провайдеры» добавьте модель. Без Docker: `cd core && npm start` (команды кода будут выключены, пока не запущен `runner.mjs` или явно не задан `SVETLANA_ALLOW_HOST_EXEC=1`; так делать не советую).

Тесты: `cd core && npm test` (26 тестов: юниты, e2e через HTTP/WebSocket, песочница, агент ПК на заглушках, регрессии по замечаниям критиков). В GitHub они запускаются сами (`.github/workflows/svetlana-core.yml`).

## Провайдеры
- **Своя модель в РФ**: preset `vllm`, адрес `http://GPU:8000/v1` (конфиг vLLM для Qwen3-VL-32B лежит в архиве АИКО v6, `deploy/`).
- **YandexGPT**: preset `yandex`, модель `gpt://<folder>/yandexgpt/latest`, API-ключ сервисного аккаунта.
- **GigaChat**: preset `gigachat`, apiKey = ключ авторизации; нужен `NODE_EXTRA_CA_CERTS` с сертификатом Минцифры.
- **Картинки/видео/голос**: отметьте возможности `image`, `video`, `tts`, `stt` у провайдера, который их реально умеет (OpenAI images/audio, Yandex SpeechKit, любой async video API через `videoEndpoint`).
При ошибке Светлана переходит к следующему провайдеру. Ключи хранятся только на сервере и в браузер не отдаются.

## Телефон
1. Веб: откройте сайт в Chrome → «Установить приложение». Голос: 🎙 (одна фраза) и 🗣 (режим разговора).
2. Управление телефоном: APK собирается в GitHub Actions (`svetlana-android-hands` → Artifacts → `svetlana-hands-debug`). Вкладка «Устройства» → «Получить ключ», включите службу «Светлана Руки» в «Спец. возможностях», вставьте `wss://ДОМЕН/ws/device` и ключ. По умолчанию все права выключены, включаете сами.

## ПК
`pip install -r core/desktop-agent/requirements.txt && python core/desktop-agent/agent.py --url wss://ДОМЕН/ws/device --token КЛЮЧ` (добавьте `--view-only`, если нужен только просмотр).

## АИКО и «Мир самозанятых»
- АИКО: `AIKO_URL=https://aiko.ru/api/ai/tool`, `AIKO_TOKEN` = токен сервисного продавца (эндпоинт есть в патче АИКО).
- МС: подключите `handleStp` из `core/connectors/self-employed-stp.js` к маршруту `/api/svetlana/tools` бэкенда, задайте там `STP_CONFIRM_SECRET`; в ядре: `SELF_EMPLOYED_URL`, `SELF_EMPLOYED_TOKEN`.

## Безопасность (коротко)
- Всё, что меняет данные, деньги, файлы, устройства или внешние системы, ждёт кнопки «Подтвердить». Токен одноразовый, подписан HMAC и привязан к точным аргументам; использованные токены хранятся на диске.
- После чтения веб-страницы, экрана или чужого файла любое действие требует подтверждения (защита от prompt-injection).
- «Разрешить на 15 минут» действует только для одной области (CRM, устройство и т. п.). Запуск кода всегда подтверждается вручную.
- Команды кода выполняются в отдельном контейнере без сети, с лимитами и списком разрешённых программ.
- Защита от SSRF (приватные IPv4/IPv6, редиректы, DNS-rebinding), CSP, SameSite cookie, проверка Origin, лимит попыток входа.
- Android: ключ в Keystore, только `wss://`, поля паролей не читаются и не заполняются.

## Честный статус
- Ядро: 26 тестов проходят, три раунда независимой проверки, все найденные дефекты закрыты. Реальный LLM в тестах заменён скриптом, качество ответов зависит от выбранной модели.
- Android-приложение в песочнице не собиралось (нет Android SDK), на устройстве не проверялось. Сборка идёт в CI (`.github/workflows/svetlana-android.yml`).
- Агент для ПК проверен тестом на заглушках экрана и мыши (Retina-масштаб, буфер обмена, только просмотр), на живом ПК не запускался.
- Фото, видео и озвучка работают, только если у подключённого провайдера есть такие API.
- Чеки в «Мой налог» Светлана не пробивает: официального API для этого нет. Она напоминает и учитывает.
- Вычет 10 000 ₽ применяет ФНС, в отчёте показан НПД до вычета.
