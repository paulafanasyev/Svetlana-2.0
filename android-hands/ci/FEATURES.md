# Что проверять в APK после сборки

Эмулятор (`emulator-smoke.sh`) ждёт строку ядра «Светлана слушает … · инструментов: N».
С интеграциями инструментов стало больше: github_*, vercel_*, vk_*, youtube_read, mail_*, mcp_*.

Ручная проверка на телефоне:
1. Вкладка «ИИ»: под заголовком строка «Светлана 2.1 · команда, свой ИИ, приоритет». Если её нет — на телефоне старая сборка.
2. Вкладка «Интеграции»: GitHub, Vercel, ВКонтакте, YouTube, Gmail, Mail.ru, Яндекс Почта — «Подключить», «Проверить связь». Ниже — MCP-серверы (адрес + токен).
3. Чат: 📤 «Поделиться чатом», ⧉ «Копировать ответ», 📄 «Файл в папку чата».
4. «Подключено»: номера 1, 2, 3… и стрелки ↑↓ — приоритет ИИ; «Проверить связь» у каждого.
5. «Свой ИИ по ссылке»: адрес, ключ — список моделей появляется сам.
6. Вкладка «Команда»: роли CTO / IT / Маркетинг и видео, кнопка «💬 Чат».
