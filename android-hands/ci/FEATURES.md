# Что проверять в APK после сборки

Эмулятор (`emulator-smoke.sh`) ждёт строку ядра «Светлана слушает … · инструментов: N».
С командой и монтажом видео инструментов стало на 3 больше (team_list, team_delegate, video_edit).

Ручная проверка на телефоне:
1. Вкладка «ИИ»: под заголовком строка «Светлана 2.1 · команда, свой ИИ, приоритет». Если её нет — на телефоне старая сборка, удалите приложение и поставьте новое.
2. «Подключено»: номера 1, 2, 3… и стрелки ↑↓ — это приоритет (сначала первый ИИ, при сбое — следующий). У каждого кнопка «Проверить связь».
3. «Свой ИИ по ссылке»: адрес (например `https://anymodel.org/v1`), ключ — список моделей появляется сам; «Проверить соединение», «Сохранить».
4. Чат: «☰ Чаты», «＋ Новый», поле «ИИ:» — у каждого чата свой ИИ (локальная модель телефона тоже в списке).
5. Вкладка «Команда»: роли CTO / IT / Маркетинг и видео, кнопка «💬 Чат».
6. Вкладка «Устройства»: браузерной кнопки «Дать Светлане видеть экран» на телефоне нет — вместо неё подсказка про «🖐 Экран и руки».
