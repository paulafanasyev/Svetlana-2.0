# Что проверять в APK после сборки

Эмулятор (`emulator-smoke.sh`) ждёт строку ядра «Светлана слушает … · инструментов: N».
С командой и монтажом видео инструментов стало на 3 больше (team_list, team_delegate, video_edit).

Ручная проверка на телефоне:
1. Вкладка «ИИ» → «Свой ИИ по ссылке»: адрес, «Список моделей», ключ, «Проверить соединение», «Сохранить».
2. Чат: «☰ Чаты», «＋ Новый», поле «ИИ:» — у каждого чата свой ИИ (локальная модель телефона тоже в списке).
3. Вкладка «Команда»: роли CTO / IT / Маркетинг и видео, кнопка «💬 Чат».
4. Вкладка «Устройства»: браузерной кнопки «Дать Светлане видеть экран» на телефоне нет — вместо неё подсказка про «🖐 Экран и руки».
