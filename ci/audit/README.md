# Исправленные workflow из аудита

У токена Светланы нет права Workflows, поэтому эти файлы лежат здесь. Их нужно скопировать поверх файлов с тем же именем в `.github/workflows/` (или выдать токену право Workflows: Read and write, и Светлана сделает это сама).

- `svetlana-android-keygen.yml`: ключ подписи создаётся только из основных веток (из другой ветки изменённый workflow мог бы унести ключ).
- `svetlana-android.yml`: в Releases публикуется только подписанный APK; без ключа отладочная сборка остаётся только артефактом.
